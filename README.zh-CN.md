# Agent Control（简体中文文档入口）

> 简体中文文档现已设为本仓库默认首页，请前往 👉 **[README.md（简体中文完整文档）](README.md)**

**Agent Control** 是面向 **Codex、Claude Code、Antigravity、Grok 和 Qoder** 的自托管桌面端与手机远程控制台：出门扫码即可查看进度、批复权限、打断纠偏与排队派活，严格只读解析本地历史，不修改原工具任何配置与数据库。

## 一行命令快速安装

**macOS / Linux：**
```bash
curl -fsSL https://raw.githubusercontent.com/guuguo/agent-control/main/install.sh | bash
```

**Windows (PowerShell)：**
```powershell
(irm https://raw.githubusercontent.com/guuguo/agent-control/main/install.ps1).TrimStart([char]0xFEFF) | iex
```
